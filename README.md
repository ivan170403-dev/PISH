# Лендинг ПИШ (поднаправление)

Статический одностраничный сайт по ТЗ: футуристичный дизайн, описание студенческого научного сообщества, блок проектов (заглушки), форма заявок.

## Форма заявок

Сейчас отправка **демо**: данные пишутся в консоль браузера (F12), показывается уведомление об успехе.

Для продакшена в `js/main.js` раскомментируйте блок `fetch` и укажите endpoint (Formspree, свой API, Telegram-бот и т.д.).

## Что утвердить позже

- Официальное название и логотип поднаправления
- Символика НГУ (после разрешения)
- Тексты проектов и этапов
- Поля формы и политика обработки данных
- Хостинг и домен (оплачивает организация)
